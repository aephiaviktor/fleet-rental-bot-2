# Fleet Rental Bot 2 v0.1.61

**Bonus Strategy** adds a profile-specific FCFS table for fleets in your watchlist. It defaults to a 3,000 ATLAS/day filter and lists fleets with the shortest minimum rental duration first. Set a Max bid in ATLAS and enable FCFS per fleet.

An open reservation uses the minimum allowed duration and a premium of one day's rate, subject to the protocol minimum. If a rival holds the reservation, FCFS can overbid repeatedly within your Max bid while at least 24 hours remain on the current rental. The bot checks funding and simulates each bid before sending.
