# Fleet Rental Bot 2 v0.1.57

Fleet Reservation Rules checks queued reservations in batches during the 30-second funding refresh. A new, changed, or removed reservation triggers a full refresh of the affected fleet so **Our bid** reflects the current defender sooner.

An empty reservation slot shows **No bid**. If a required rental account cannot be read, the app keeps its last good row and retries. When early LCFS simulation finds newer contract data, the app refreshes the fleet and checks again when it is eligible.
