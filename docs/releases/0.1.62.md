# Fleet Rental Bot 2 v0.1.62

**Bonus Strategy** scans SRSLY for fleets with reservations enabled, including fleets outside Fleet Reservations. Use **Scan market** to refresh immediately. Set **Min rate/d** to 0 to show every reservable fleet.

Set a **Max bid** and enable **FCFS** directly from the market list. Existing rules and caps carry over per Player Profile. Fleet Reservations continues to control its existing watchlist.
