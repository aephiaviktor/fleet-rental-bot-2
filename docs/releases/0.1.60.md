# Fleet Rental Bot 2 v0.1.60

**ATLAS Earned** uses historical SOL/USD and ATLAS/USD prices from the authenticated Aephia Data API. The app uses the Aephia API key already saved in Settings.

The fee conversion uses the last available observation for each token on the previous UTC day. Refresh earnings to load Aephia prices for older bids. If either observation is missing, the converted fee, net profit, and APR show a dash.
