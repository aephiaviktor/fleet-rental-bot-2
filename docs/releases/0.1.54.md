# Fleet Rental Bot 2 v0.1.54

Check now flags **Reservations closed** for contracts with reservations disabled or a pending closure. For eligible LCFS fleets, it warns about **Low SOL**, **Missing account**, and **Check authority**. Hover over the warning for details.

The app compares the signing wallet’s SOL with the message fee and configured tip. The early simulation uses the same LCFS instructions and can also detect insufficient SOL for account creation. It runs unsigned in the background, one fleet at a time, with a pause around upcoming LCFS attempts. A simulation result applies to the contract and settings checked at that time. The final bid still uses fresh chain state.
