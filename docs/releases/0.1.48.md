# Fleet Rental Bot 2 v0.1.48

- Add read-only **Allowed Days** and **Cancel Delay** columns immediately after **Ending In**.
- Show the contract's minimum–maximum rental duration in days, such as `5–40`.
- Show the contract's minimum cancellation notice as `5d`, `12h`, `2d 12h`, or `Instant`. Preserve minutes and seconds if present.
- Refresh both columns from live contract data. Missing or older cached cancellation data remains unavailable (`—`) until refreshed.
- Show both new columns once for existing watchlists while preserving other column preferences. They can then be hidden normally.
- Keep the watchlist compatible with v0.1.47. Rental rules and bidding behavior are unchanged.

The cancellation column describes the contract terms for a new rental; existing rentals retain their snapshotted terms.
